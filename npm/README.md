# RestFlow CLI npm Package

This package provides the RestFlow CLI binary for multiple platforms.

## Installation

```bash
npm install -g restflow-cli
```

## Usage

After installation, both `restflow` and `rf` commands will be available:

```bash
restflow --help
rf --help
restflow daemon start
restflow
```

## Supported Platforms

- macOS (Intel & Apple Silicon)
- Linux (x64 & ARM64)
- Windows (x64; ARM64 installs use the x64 binary)
